# PC-98/IBM PC Web Patcher

PC-98과 IBM PC 게임의 다중 파일 한국어 패치를 브라우저에서 적용하기 위한 GitHub Pages 프로젝트다.

다음 두 화면을 제공한다.

- `index.html`: 전체 게임 목록, 검색 및 플랫폼 필터
- `patcher.html?game=게임ID`: 게임 정보와 실제 브라우저 패치 화면

게임 이미지는 `images/games/<게임ID>/` 아래에 저장한다. 자세한 파일명과 형식은 `images/README.md`를 참고한다.

와룡전 PC-98 패키지는 게임 폴더의 17개 대상 파일을 SHA-256으로 검사하고 브라우저 내부에서 VCDIFF를 적용한다. 검증된 변경 파일과 공용 에뮬레이터 폰트는 ZIP으로 내려받는다. 원본 게임 파일은 서버로 전송되지 않는다.

## 패치 사용

1. 목록에서 와룡전을 선택한다.
2. 수정되지 않은 일본어판 게임 폴더를 선택한다.
3. 17개 대상 파일의 검사가 끝나면 패치 ZIP 생성 버튼을 누른다.
4. 결과 ZIP의 게임 파일을 백업한 원본 폴더에 덮어쓴다.
5. `_emulator-font`의 BMP는 사용하는 에뮬레이터의 폰트 설정에 지정한다.

## 로컬에서 보기

정적 파일 서버를 실행한다.

```powershell
npm start
```

또는 VS Code Live Server와 같은 정적 서버를 사용할 수 있다.
